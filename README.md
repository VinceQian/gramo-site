# 🌊 DiveGuard Official Website

**Stay Connected, Even Underwater.**

DiveGuard is an intelligent underwater communication and safety system that keeps divers connected, monitored, and protected — even in the most challenging ocean environments.

---

## 📋 Project Overview

This is the official website for DiveGuard, featuring 8 comprehensive pages showcasing our innovative underwater safety technology, team, market opportunity, and technical specifications.

### 🎯 Project Goals

- Showcase DiveGuard's innovative underwater communication and safety system
- Present our interdisciplinary team and mission
- Demonstrate market opportunity and global impact
- Provide technical details for potential partners and investors
- Enable contact and collaboration opportunities

---

## 🌐 Website Structure

### ✅ Completed Pages

1. **HOME (index.html)** - `/` or `/index.html`
   - Hero section with animated background

   - Call-to-action sections

   - Mission and vision statements
   - Core values (Innovation, Safety, Accessibility, Environmental Responsibility)

   - Team member profiles with hover effects

   - Join us call-to-action

4. **INNOVATION (innovation.html)** - `/innovation.html`
   - Five key features with detailed descriptions
   - System architecture diagram
   - Cost comparison (70% reduction vs. existing systems)
   - Technical advantages

5. **MODEL GALLERY (gallery.html)** - `/gallery.html`
   - Visual gallery of prototypes and designs
   - Development timeline from concept to production
   - Evolution showcase (Prototype 1 → Prototype 2 → Pre-Production)
   - Interactive gallery with lightbox capability

6. **MARKET & IMPACT (market.html)** - `/market.html`
   - Market statistics and growth projections
   - Interactive Chart.js visualization of market growth
   - Problem vs. solution comparison
   - SDG alignment (SDG 3 & SDG 14)

7. **TECHNOLOGY (technology.html)** - `/technology.html`
   - System architecture layers

8. **CONTACT (contact.html)** - `/contact.html`
   - Contact form with validation
   - Contact information (email, phone, address)
   - Social media links
   - Partnership opportunities section

## 🎨 Design Features

### Color Palette
- **Primary Colors**: Deep Ocean Blue (#0A2540, #1E3A5F)
- **Accent Colors**: Cyan (#00D9FF), Teal (#4ECDC4), Orange (#FF6B35)
- **Neutral Colors**: Dark Gray (#2D3748), Light Gray (#E2E8F0), White (#FFFFFF)

### Animation & Effects
- **Particles.js**: Animated particle background on hero sections
- **AOS (Animate On Scroll)**: Smooth scroll-triggered animations throughout
- **Custom CSS animations**: Floating effects, gradient animations, hover transitions
- **Smooth scrolling**: Enhanced navigation experience
- **Interactive elements**: Hover effects on cards, buttons, and navigation

### Typography
- **Primary Font**: Inter (body text, UI elements)
- **Display Font**: Space Grotesk (headings, titles)
- Font loaded via Google Fonts CDN

## 🛠️ Technologies Used

### Core Technologies
- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with custom properties, flexbox, grid
- **JavaScript (ES6+)**: Interactive functionality and animations

### Libraries & Frameworks
- **Particles.js** (v2.0.0) - Particle animation effects
- **AOS** (v2.3.4) - Scroll animations
- **Chart.js** (latest) - Data visualization (market page)
- **Font Awesome** (v6.4.0) - Icon library
- **Google Fonts** - Custom typography

### CDN Resources
All external libraries are loaded via CDN for optimal performance:
- jsDelivr CDN for reliable library delivery
- Google Fonts CDN for typography
- Font Awesome CDN for icons
