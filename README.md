# Gramo — Official Product Website

**Smart Weighing, Clear Eating.**

Gramo is a calorie-tracking utensil that automatically weighs every bite — making weight loss and nutritional management accessible to everyone.

Built by **Equimeal** (Equality + Meal) · TEAM 智味勺 · 2025–2026 Conrad Challenge, Health & Nutrition.
